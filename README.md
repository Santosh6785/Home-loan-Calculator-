# Home Loan Eligibility Calculator

A Progressive Web App (PWA) for quick home loan eligibility assessment.
Designed for bank officials and Direct Selling Agents (DSAs).

## Features

- Supports Home Loan, PLAP, and Top-Up loan products
- ROI calculation based on CIBIL score slabs
- BSP variant selection (Standard, Maxgain, Suraksha, Cred HL)
- Handles salaried and self-employed applicants
- Co-applicant income support
- NRI applicant handling charges
- Processing fee and GST breakdown
- Works fully offline after first load (service worker cache)
- Installable on Android and iPhone home screen

## How to Install on Phone

1. Open the link in **Chrome** (Android) or **Safari** (iPhone)
2. Tap **"Add to Home Screen"** when prompted
3. The app installs like a native app — no Play Store or App Store needed
